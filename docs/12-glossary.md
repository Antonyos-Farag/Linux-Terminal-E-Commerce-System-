# Glossary

- **Alias** – a shell shortcut name for a command, stored in `~/.bashrc`.
- **BASE_PATH** – compile-time macro holding the root data directory.
- **`cat`** – concatenate/print file contents.
- **`chmod`** – change file mode (permissions).
- **`cp`** – copy files.
- **Fall-through** – in C `switch`, execution continuing into the next case without `break`.
- **Glob** – shell wildcard pattern (e.g. `product*.txt`).
- **`grep`** – search text using patterns.
- **`head`/`tail`** – show first/last N lines.
- **`ln -s`** – create a symbolic link.
- **`mkdir -p`** – create directory including parents.
- **Redirection** – `>` overwrite, `>>` append.
- **`rmdir`** – remove an empty directory.
- **`scanf`** – formatted input from stdin.
- **`system()`** – run a shell command from C.
- **Symlink** – a file that points to another path.
